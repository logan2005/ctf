# 🚀 Quick Start Guide - CyberQuest CTF

## Your CTF Platform is Ready!

The server is currently running at: **http://localhost:8080**

## 📋 What to Do Next

### 1. Open the Platform
Open your web browser and navigate to:
```
http://localhost:8080
```

### 2. First Steps
When the page loads, you'll see:
- **Left Side**: Terminal simulation and challenge description
- **Right Side**: AI Chatbot assistant
- **Top**: Level indicator and score tracker

### 3. Start Level 1
1. Click the **"Objective"** button in the chatbot to see your goals
2. Type `help` in the terminal to see available commands
3. Try `ls -la` to list all files (including hidden ones)
4. Use `cat .hidden_flag` to read the hidden file
5. Submit the flag you find!

## 🎯 Quick Command Reference

### Essential Commands for Level 1
```bash
ls -la          # List all files including hidden
cd [directory]  # Change directory
cat [file]      # Read file contents
pwd             # Show current directory
```

### Get Help
- Type `help` in the terminal for all commands
- Click **"Hint"** in the chatbot for progressive hints
- Ask the chatbot questions directly!

## 💡 Pro Tips

1. **Read Everything**: Flags are often hidden in file contents
2. **Use Hints Wisely**: You get 3 hints per level, but they reduce your score
3. **Explore**: Try different commands and directories
4. **Ask the Chatbot**: It's there to help you learn!

## 🎨 Features to Notice

- **Matrix Effect**: Subtle falling characters in the background
- **Glow Effects**: Elements pulse and glow when active
- **Smooth Animations**: Watch the progress tracker update
- **Terminal History**: Use ↑ and ↓ arrows to navigate command history

## 🔧 Keyboard Shortcuts

- `Ctrl/Cmd + K` - Clear terminal
- `Ctrl/Cmd + H` - Get a hint
- `Escape` - Focus terminal input
- `↑/↓` - Navigate command history

## 📊 Scoring

- **1000 points** base per level
- **+500 points** for completing in under 2 minutes
- **-100 points** per hint used

Try to complete all 5 levels with the highest score possible!
